1. Mission & Problem Statement
KAVACH ('Shield') is a hybrid AI + physics system that predicts energetic electron particle fluxes (>2 MeV) at geostationary orbit (GEO, ~35,786 km altitude). Satellites at GEO are vulnerable to deep-dielectric charging caused by energetic electron buildup — this can cause anomalies or permanent damage to on-board electronics.

The algorithm must produce:
T+30 to 45 minute forecast — operational warning window (MANDATORY minimum)
T+6 hour forecast — medium-range planning
T+12 hour forecast — extended planning
Calibrated uncertainty bands (quantile outputs, not just point estimates)
Green / Yellow / Red risk index based on deep-dielectric charging thresholds
Explainability: which solar wind driver is most important at each horizon

Why existing approaches fall short
Black-box ML: one neural network, solar wind in → flux out. No physical grounding.
No uncertainty quantification — operators get a number, not a confidence level.
Ignore data scarcity: ISRO has only 1–2 years of Indian-longitude GRASP data. Training only on GRASP will overfit.
No regime awareness: quiet-time physics and storm-time physics are fundamentally different. One model cannot fit both equally.
Ignore magnetometer ULF signals — a known 30-min precursor to flux enhancements that most teams will miss.

2.3  OMNI Solar Wind Parameters
→ CDAWeb OMNI : https://cdaweb.gsfc.nasa.gov/pub/data/omni
Dataset: OMNI_HRO_1MIN (1-minute high resolution) or OMNI_HRO_5MIN (5-minute)
Use 5-minute version to match GOES cadence: cdaweb.gsfc.nasa.gov → search OMNI_HRO_5MIN
Parameters to download (select these columns specifically):
Vsw — solar wind speed (km/s)
BZ_GSM — IMF Bz in GSM coordinates (nT) — southward = negative = dangerous
BY_GSM — IMF By in GSM coordinates (nT)
BT — total IMF magnitude (nT)
Np — proton number density (cm⁻³)
Pressure — solar wind dynamic pressure (nPa) — or compute from Np × Vsw²
KP — Kp geomagnetic index (0–9 scale)
DST — Dst ring current index (nT) — negative during storms
AE — auroral electrojet index (nT) — substorm activity
Format: CDF or ASCII depending on access method
These are bow-shock-shifted values — already propagated from L1 to Earth's nose. Use these, not raw ACE/Wind L1.
⚠  Fill value in OMNI is 9999.9. Replace with NaN before any computation or the coupling function will explode.

3.1 GOES CDF Ingestion
# data/ingest_goes.py
import cdflib, pandas as pd, numpy as np, glob, os

GOES_FLUX_VARS = {
    'goes13': 'E2ChanP',          # EPEAD >2 MeV channel
    'goes15': 'E2ChanP',
    'goes16': 'AvgDiffElectronFlux',   # MPS-HI — check cdf.cdf_info()
    'goes17': 'AvgDiffElectronFlux',
    'goes18': 'AvgDiffElectronFlux',
}

def load_goes_cdf(filepath, satellite='goes16'):
    cdf = cdflib.CDF(filepath)
    # Print variable names first time: print(cdf.cdf_info()['rVariables'])
    epoch = cdflib.cdfepoch.to_datetime(cdf['Epoch'])
    flux_var = GOES_FLUX_VARS[satellite]
    flux = cdf[flux_var][:]
    flux = np.where(flux <= 0, np.nan, flux)   # remove fill values
    df = pd.DataFrame({'flux': flux}, index=pd.DatetimeIndex(epoch))
    df.index = df.index.tz_localize(None)       # strip timezone
    return df.resample('5T').mean()

def load_all_goes(data_dir):
    frames = []
    for f in sorted(glob.glob(os.path.join(data_dir, '**/*.cdf'), recursive=True)):
        sat = 'goes16' if 'g16' in f else 'goes18' if 'g18' in f else 'goes15'
        frames.append(load_goes_cdf(f, sat))
    return pd.concat(frames).sort_index().loc[~pd.Index.duplicated(pd.concat(frames).sort_index().index)]

# data/ingest_omni.py
import cdflib, pandas as pd, numpy as np

OMNI_COLS = ['Vsw','BZ_GSM','BY_GSM','BT','Np','Pressure','KP','DST','AE']
FILL_VALUES = {col: 9999.9 for col in OMNI_COLS}  # OMNI fill value

def load_omni_cdf(filepath):
    cdf = cdflib.CDF(filepath)
    epoch = cdflib.cdfepoch.to_datetime(cdf['Epoch'])
    data = {}
    for col in OMNI_COLS:
        try:
            arr = cdf[col][:].astype(float)
            arr[arr >= 9999.0] = np.nan   # replace fill value
            data[col] = arr
        except: pass
    df = pd.DataFrame(data, index=pd.DatetimeIndex(epoch))
    return df.resample('5T').mean()

3.3 INTERMAGNET Magnetometer Ingestion (IAGA-2002 format)
# data/ingest_magnetometer.py
import pandas as pd, numpy as np
from scipy.signal import butter, filtfilt

def load_iaga2002(filepath):
    '''Parse INTERMAGNET IAGA-2002 .min file'''
    rows = []
    with open(filepath) as f:
        for line in f:
            if line.startswith('DATE'): continue   # skip header
            if line[0] in ' \t' or len(line) < 30: continue
            try:
                date_str = line[:10].strip()
                time_str = line[11:19].strip()
                vals = line[20:].split()
                H = float(vals[0])   # H-component is first column
                if H > 99999: H = np.nan  # fill value
                rows.append({'datetime': date_str+' '+time_str, 'H': H})
            except: pass
    df = pd.DataFrame(rows)
    df['datetime'] = pd.to_datetime(df['datetime'])
    return df.set_index('datetime').resample('1T').mean()

def compute_ulf_power(H_series, resample_to='5T'):
    '''Band-pass to Pc5 (1.7–6.7 mHz) then rolling variance'''
    H = H_series.interpolate(limit=30).values   # fill gaps < 30 min
    fs = 1/60   # 1-min cadence → fs = 1/60 Hz
    b, a = butter(4, [1.7e-3, 6.7e-3], btype='band', fs=fs)
    H_pc5 = filtfilt(b, a, np.nan_to_num(H))
    power = pd.Series(H_pc5, index=H_series.index).rolling(45).var()
    power = np.log10(power.clip(lower=1e-6))  # log for stability
    return power.resample(resample_to).mean()   # downsample to 5-min

4. Feature Engineering
# data/features.py — run AFTER merging all sources
import pandas as pd, numpy as np

def engineer_features(df):
    '''df has columns: flux, Vsw, BZ_GSM, BY_GSM, BT, Np, Pressure, KP, DST, AE, H_ulf'''

    # 1. Log-transform flux (do before anything else)
    df['log_flux'] = np.log10(df['flux'].clip(lower=0.1))

    # 2. Lagged flux history (radiation belt has memory)
    for lag_steps, label in [(12,'1h'),(36,'3h'),(72,'6h'),(144,'12h'),(288,'24h')]:
        df[f'flux_lag_{label}'] = df['log_flux'].shift(lag_steps)

    # 3. Newell IMF coupling function (best single predictor)
    Vsw = df['Vsw']; By = df['BY_GSM']; Bz = df['BZ_GSM']
    Bt = np.sqrt(By**2 + Bz**2)
    theta = np.arctan2(By, Bz)
    df['Ec'] = (Vsw**(4/3)) * (Bt * np.sin(theta/2))**(8/3)
    df['Ec'] = df['Ec'].clip(lower=0)

    # 4. Dynamic pressure (if not in OMNI, compute it)
    df['Pdyn'] = 0.5 * 1.67e-27 * (df['Np']*1e6) * (df['Vsw']*1e3)**2 * 1e9

    # 5. ULF wave power — already computed in ingest_magnetometer.py
    #    df['ULF_power'] column should already be present after merge

    # 6. Southward IMF duration (how long Bz has been negative)
    df['Bz_neg'] = (df['BZ_GSM'] < 0).astype(int)
    df['Bz_neg_dur'] = df['Bz_neg'].groupby(
        (df['Bz_neg'] != df['Bz_neg'].shift()).cumsum()).cumcount() * 5  # minutes

    # 7. Dst rate of change (storm onset/recovery detector)
    df['dDst_dt'] = df['DST'].diff() / 5.0   # nT per minute

    # 8. AE 1-hour rolling mean (substorm activity)
    df['AE_1h'] = df['AE'].rolling(12).mean()

    # 9. Regime label (rule-based)
    df['regime'] = df.apply(classify_regime, axis=1)

    return df.dropna()

def classify_regime(row):
    Kp, Dst, dDst = row['KP'], row['DST'], row.get('dDst_dt', 0)
    if Kp > 5 and Dst < -50:     return 2   # main_phase
    elif dDst > 5:               return 3   # recovery
    elif Kp >= 3 or Dst < -20:   return 1   # storm_onset
    else:                        return 0   # quiet

6.2 Engine 2 — 1-D Radial Diffusion Physics Solver
# models/radial_diff.py
import numpy as np
from scipy.integrate import solve_ivp

def compute_DLL(L, Kp):
    '''Brautigam & Albert (2000) empirical diffusion coefficient'''
    return 10**(-9.325 + 0.506*Kp) * L**10

def loss_timescale(L, Kp):
    '''Electron loss timescale in seconds (Kp dependent)'''
    tau_days = 10**( -0.5*Kp + 3.0 - 0.5*(L-4) )
    return tau_days * 86400  # convert to seconds

def radial_diffusion_rhs(t, f, L, Kp):
    DLL = compute_DLL(L, Kp)
    tau = loss_timescale(L, Kp)
    dL = L[1] - L[0]
    f_norm = f / L**2
    diff = np.zeros_like(f)
    for i in range(1, len(L)-1):
        D_mid_p = 0.5*(DLL[i+1]+DLL[i])
        D_mid_m = 0.5*(DLL[i]+DLL[i-1])
        diff[i] = (L[i]**2/dL**2)*(D_mid_p*(f_norm[i+1]-f_norm[i]) - D_mid_m*(f_norm[i]-f_norm[i-1]))
    return diff - f/tau

def run_physics_forecast(f0_profile, L_grid, current_Kp, horizons=[1800,21600,43200]):
    '''f0_profile: initial PSD on L_grid. Returns flux at L=6.6 for each horizon.'''
    sol = solve_ivp(
        radial_diffusion_rhs, [0, max(horizons)], f0_profile,
        method='RK45', t_eval=horizons, args=(L_grid, current_Kp)
    )
    geo_idx = np.argmin(abs(L_grid - 6.6))  # GEO is at L~6.6
    return sol.y[geo_idx, :]  # PSD at GEO for each horizon

7. Regime-Aware Ensemble
# models/ensemble.py
import numpy as np

REGIME_WEIGHTS = {
    0: {'tft': 0.70, 'phys': 0.30},   # quiet
    1: {'tft': 0.50, 'phys': 0.50},   # storm onset
    2: {'tft': 0.30, 'phys': 0.70},   # main phase
    3: {'tft': 0.60, 'phys': 0.40},   # recovery
}

def ensemble_forecast(tft_log_flux, phys_log_flux, regime_code):
    w = REGIME_WEIGHTS[regime_code]
    fused = w['tft']*tft_log_flux + w['phys']*phys_log_flux
    # Agreement = 1 when both engines agree, 0 when they diverge
    agreement = 1.0 - np.abs(tft_log_flux - phys_log_flux) / (np.abs(fused)+1e-6)
    agreement = float(np.clip(agreement, 0, 1))
    return fused, agreement

def classify_risk(log_flux_p50, uncertainty_score):
    flux = 10**log_flux_p50
    # If engines strongly disagree, bump risk up by one level
    bump = uncertainty_score > 0.4
    if flux > 1e4 or (flux > 1e3 and bump):   return 'RED',    'HIGH RISK — immediate alert'
    elif flux > 1e3 or (flux > 1e2 and bump): return 'YELLOW', 'ELEVATED — advisory to ops'
    else:                                      return 'GREEN',  'NOMINAL — log and monitor'

13. Known Pitfalls — Read Before Coding

#
Pitfall
How to Avoid
1
OMNI fill value 9999.9 — will corrupt Ec coupling function to infinity
Replace all values ≥ 9999 with NaN immediately on load
2
GOES CDF variable names differ per satellite
Call cdf.cdf_info() on each satellite's file and hardcode correct var name
3
Log10 of zero flux → -inf
Clip flux to minimum 0.1 pfu before log10 transform
4
Scaler fitted on full dataset → data leakage
Fit StandardScaler ONLY on train set. Transform val and test using train scaler.
5
INTERMAGNET gaps corrupt ULF filter
Interpolate linearly for gaps < 30 min. Mask larger gaps. NaN to zero before filtfilt.
6
Darts version mismatch breaks model load
Pin u8darts==0.27.0 in requirements.txt
7
GRASP column names unknown until download
Open file, print first 20 lines, update ingest_grasp.py column rename accordingly
8
Streamlit reloads model on every interaction
Wrap model load in @st.cache_resource — loads once per session
9
GOES-13/15 EPEAD vs GOES-16/18 MPS-HI sensor discontinuity
Apply linear regression correction on 2017–2020 overlap period before merging
10
ULF power spans many orders of magnitude
Log10-transform ULF_power before using as feature. Clip lower bound to 1e-6.
11
Chronological split essential
Never shuffle. pd.concat + sort_index. Split by year, not random.
12
GRASP registration delay
Register at pradan1.issdc.gov.in on Day 1 — can take 24–48 hrs to approve
